# Folio v0.7.1

Existing text can now grow into available page space. Folio preserves the original font size and baseline, checks the visible page boundary, and rejects new or expanded overlap with nearby source text and graphics. The original text run's width is no longer a hard limit.

Added text boxes now have a **Font** picker with twelve choices: Helvetica, Times and Courier in regular, bold, italic and bold italic styles. Font choices survive undo/redo, recovery, editable save/reopen and flattened export. Older Folio annotations keep Helvetica.

Choose **Edit text** to replace an existing run, or **Text** to add a box and select its font in Properties. Replacements remain single-line; automatic paragraph reflow and embedded/subset-font editing are not included. See the [support details](https://github.com/willherr72/folio/blob/v0.7.1/docs/existing-text-editing.md) and [broader font roadmap](https://github.com/willherr72/folio/blob/v0.7.1/docs/font-support-roadmap.md).

Download and extract the Windows x64 portable ZIP, then run **Folio.exe**. Keep the resources folder beside it. WebView2 Runtime is required.

Validation: 176 frontend tests, 63 native tests, 48 browser font/rotation checks, and packaged desktop save/reopen/copy/search checks. [Verification details](https://github.com/willherr72/folio/blob/v0.7.1/docs/verification-v0.7.1.md).
