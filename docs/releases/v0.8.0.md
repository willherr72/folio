# Folio v0.8.0

Added text boxes can now use installed fonts and imported local font files. Select a box and choose **More fonts…** in Properties to search the font catalog or import a static TrueType-outline TTF/OTF.

- The exact font is embedded in saved PDFs, so reopening or sharing needs no installed font or original font file.
- Font choices survive undo/redo, multiple tabs, recovery and editable or flattened export.
- Font permissions and character coverage are checked, with explanations for unsupported formats and characters.

This release completes #11. Editing existing embedded/subset fonts (#12) and complex shaping (#13) remain separate work. [Supported fonts and limits](../font-support-roadmap.md).

Download the Windows x64 portable ZIP, extract it, and run **Folio.exe** with the resources folder beside it. WebView2 Runtime is required.

Verified with 187 frontend tests, 81 native tests, 16 browser rotation combinations and the packaged Windows workflow. Independent pypdf/PyMuPDF inspection confirmed exact embedded font bytes and matching editable/flattened appearance. [Verification report](../verification-v0.8.0.md).
