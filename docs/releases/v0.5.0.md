# Folio v0.5.0

Reusable signatures and review annotations for everyday PDF work.

- Save named signatures locally, preview and reuse them, rename them, or remove them from the library.
- Resize placed signatures and other ink proportionally in Properties.
- Highlight selectable PDF text across lines, including rotated pages and changing zoom.
- Place comments and start typing immediately. The Review list jumps to highlights and comments throughout the document.
- Change annotation notes/colors, move comments, delete items and undo/redo independently in each tab.
- Save highlights and comments as standard PDF annotations and reopen them with editing controls. Recovery preserves them too.

Download and extract the Windows ZIP, then run **Folio.exe**. Keep its resources folder beside it. WebView2 Runtime is required.

Signatures stay in this application's local profile and are visual marks, not certificate-based signing. Highlighting requires embedded text; OCR is not included. Added text and ink still become page content on export; restoring their editing handles is planned for v0.6.0.

Verified with 129 frontend tests, 38 ordinary native tests plus two explicit printing tests, browser rotation/compositing checks, independent MuPDF inspection, and real desktop export/reopen and crash recovery.
