# Folio v0.6.0

Pick up editing where you left off, even after saving and reopening a PDF.

- Save added text, drawings and signatures as portable editable PDF annotations. Their positions, colors, sizes and orientation return with editing controls in Folio.
- Keep additions aligned when pages are rotated, duplicated, reordered or combined. Original files and sidecars are not needed to reopen the saved PDF.
- Use Save a copy or Ctrl+S for the editable version. The Save arrow offers **Flatten text and ink** when you want those additions as page content. Highlights and comments remain annotations.
- Preserve the visible native annotation when another reader changes its appearance or data in a way Folio cannot safely import.
- Restore older recovery checkpoints while respecting later deletions.
- Exercise a redistributable compatibility corpus covering embedded fonts, dense tables, mixed sizes, cropped/rotated pages, a 300-page document and a 96 MiB scan.

Download and extract the Windows ZIP, then run **Folio.exe**. Keep its resources folder beside it. WebView2 Runtime is required.

The editable PDF format and its compatibility tradeoffs are documented in `docs/editable-pdf-format.md`. Performance measurements, hardware and reproduction commands are in `docs/corpus/README.md`; they are observed baselines, not a Foxit parity claim.

Editing original words in a PDF remains the next milestone (#8). Drawn signatures are visual marks, and scanned text still requires OCR to become selectable.

Verified with 146 frontend tests, 45 ordinary native tests plus 2 explicit Windows printing tests, 64 independent-reader rotation pairs, browser interaction checks, real desktop editing/reopen and crash recovery, and measured large-document workloads.
