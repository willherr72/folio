Folio 0.3.1 fixes slow switching between PDF tabs.

- Batched text measurements eliminate thousands of unnecessary layout passes on text-heavy pages.
- Recently rendered pages are reused when you return to a tab.
- A memory-limited cache evicts older images and releases a document's images when its tab closes.

Download **Folio-v0.3.1-windows-x64.zip**, extract it, and run **Folio.exe**. Keep the resources folder beside the executable. Windows x64 and Microsoft Edge WebView2 Runtime are required.

The controlled browser benchmark improved from about 1.44 seconds to 47 milliseconds per switch on a 1,000-character page. Results depend on document complexity and hardware; this is not a Foxit comparison. Details and Windows verification are recorded in [verification notes](https://github.com/willherr72/folio/blob/v0.3.1/docs/verification.md).
