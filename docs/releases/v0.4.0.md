# Folio v0.4.0

Recovery, search, and printing make Folio more useful for everyday PDF work.

- **Crash recovery:** restore open tabs, edits, page organization, zoom and scroll after an unexpected exit. Local source snapshots keep recovery working when original PDFs move.
- **Search (Ctrl+F):** find embedded PDF text and added text, highlight results and jump between matches. Each tab retains its own search.
- **Print (Ctrl+P):** print current edits, including unsaved changes. Choose all/current/custom pages, fit or actual sizing, then printer, paper and copies in Windows.

Download and extract the Windows ZIP, then run **Folio.exe**. Keep its resources folder beside it. WebView2 Runtime is required.

Recovery is local and does not overwrite original PDFs. It checkpoints after one second of inactivity or within five seconds during continuous editing. Restoring starts a fresh undo history. Confirmed normal closing discards recovery data.

Printing uses raster output, up to 2400 pixels wide; use Save a copy for vector-preserving PDF export. Opened source PDFs have a 512 MiB limit. Physical-printer behavior has not been verified; Microsoft Print to PDF output and native dialog cancellation were tested.

Verified with 100 frontend tests, 27 standard native tests plus two explicit printer/dialog tests, browser rotation/selection/search checks, and a real desktop crash/restart with moved originals.
