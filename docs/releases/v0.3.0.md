Folio 0.3.0 adds document tabs, faster text entry, signature previews and copying
of embedded PDF text.

- Open each PDF in a new tab. Switch documents without losing edits, undo/redo
  history, selected page, zoom or scroll position.
- Use Ctrl+Tab/Ctrl+Shift+Tab to switch tabs and Ctrl+W to close the active tab.
- Keep Add PDF for appending pages to the current document. Open creates a new tab.
- Create a text note and type immediately: Content focuses with its placeholder selected.
- Preview a signature at the pointer before clicking to place it. Press Escape to cancel.
- In Select mode, drag over embedded PDF text and press Ctrl+C. Spaces and line
  breaks are preserved, including on rotated and zoomed pages.
- Confirm before closing an unsaved tab. Closing Folio checks for unsaved changes
  in every tab, including inactive documents; cancelling preserves the open tabs.

The portable package is **Folio-v0.3.0-windows-x64.zip**. Extract it and run
**Folio.exe**, keeping the resources folder beside the executable. Requires
Windows x64 and Microsoft Edge WebView2 Runtime.

Scanned pages without embedded text remain image-only; OCR is not included.
Existing PDF words can be selected and copied but cannot be edited. Drawn
signatures are visual marks, not certificate-based digital signatures. See the
README for supported text characters and other prototype limits.

Release validation is in progress. Frontend tests/build, native tests and browser
