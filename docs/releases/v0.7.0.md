# Folio v0.7.0

Folio can now change existing PDF text in supported documents. Choose **Edit text**, click an outlined text run, enter the replacement, and apply. The PDF content changes, so copy, search and saved files contain the replacement.

- Keep the original font, size, color and placement, with undo/redo and independent duplicate pages.
- Retain added text, drawings, signatures and review annotations while editing source text.
- Reject unsupported fonts/layouts and replacements that do not fit; errors keep your typed replacement available.
- Save and reopen edited PDFs without the original file. Original PDFs remain protected from overwrite.

This first version supports the standard Latin Helvetica, Times and Courier font families and single-line printable ASCII text. Embedded/subset fonts, text inside forms, paragraph reflow and OCR are not included. This feature is not secure redaction. See [support and preservation details](https://github.com/willherr72/folio/blob/v0.7.0/docs/existing-text-editing.md).

Download and extract the Windows x64 portable ZIP, then run **Folio.exe**. Keep the resources folder beside the executable. WebView2 Runtime is required.

Validation: 172 frontend tests, 54 native tests, 32 browser rotation/zoom checks, and packaged desktop save/reopen/copy/search checks. [Verification details](https://github.com/willherr72/folio/blob/v0.7.0/docs/verification-v0.7.0.md).
