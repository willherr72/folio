Folio 0.2.0 adds drawing and a more comfortable everyday reading experience.

- Draw directly on PDFs with adjustable pen color and width.
- Scroll continuously through pages, or choose single-page view.
- Hold Ctrl and scroll to zoom around the pointer.
- Choose Light, Dark or System theme and remember your preferences.
- Reorder pages by dragging thumbnail handles, with a visible insertion marker.
- Use centered app confirmations for unsaved changes.

Download **Folio-v0.2.0-windows-x64.zip**, extract it, and run **Folio.exe**.
Keep the resources folder beside the executable. Requires Windows x64 and
Microsoft Edge WebView2 Runtime.

This remains a prototype. Existing PDF text editing, OCR, redaction and
certificate-based digital signatures are not included. See the README for
font support and other current limits.
