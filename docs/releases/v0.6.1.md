# Folio v0.6.1

Faster revisits to dense PDF pages and bounded retention of sidebar thumbnails. In the packaged 300-page test, average warm dense-tab DOM/text readiness improved from 848 ms to 632 ms across 12 switches per version.

- Cached pages reuse measured text geometry, avoiding thousands of repeated glyph layout reads when switching tabs.
- Off-screen thumbnails release their image references so the existing 60-entry / 96 MiB estimated decoded-image cache can evict old images.
- The 300-page thumbnail traversal retained 60 image URLs instead of 302. Total process RAM remains variable; no percentage RAM reduction is claimed.
- Selection, copying and highlighting are verified before and after a cached remount across all source/editor rotations at two zoom levels.
- Regression coverage includes simultaneous duplicate pages, cache eviction, late renders and batched visibility events.

Download and extract the Windows x64 portable ZIP, then run **Folio.exe**. Keep the resources folder beside the executable. WebView2 Runtime is required. Existing preferences, signatures and recovery data remain compatible.

See [the performance verification report](../performance-v0.6.1.md) for measurements and limitations. Testing on an actual lower-memory computer remains [issue #10](https://github.com/willherr72/folio/issues/10); CPU throttling is only a simulation.
