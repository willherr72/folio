# Mixed paragraph layout implementation plan

> Execute inline with superpowers:executing-plans and test-driven-development.
> The user authorized continued implementation without routine approval gates.

**Goal:** Lay out attributed paragraphs with verified per-style font metrics,
preserved word/style boundaries, alignment, and measured vertical fit as the next
part of the full mixed publication milestone.

**Architecture:** Keep a deterministic layout kernel separate from source/font
admission. A read-only engine staging method re-inspects the immutable source,
checks expected text and style IDs, measures the bound fonts, and invokes the
kernel. Publication will consume that same plan and independently verify its
encoded output; this step does not expose mixed editing to the GUI.

**Tech stack:** Existing Rust/PDFium/lopdf; no added dependency.
**Spec:** `2026-10-23-mixed-paragraphs.md`, milestone 4 remains incomplete until
publication and explicit style overrides are verified.

## Contracts

- Maximum logical text 4096 UTF-8 bytes, 64 verified styles, 256 lines, bounded
  input/output fragments. Preserve ASCII spaces and hard LF breaks exactly.
- Font changes inside a word are not wrap opportunities. Tabs/CR/unsupported
  glyphs/unknown styles fail before layout. Source fonts retain their encoding
  admission; Unicode representation does not imply shaping support.
- Use font ascent/descent and measured glyph ink, including accents/overhangs.
  Blank lines inherit the style of their hard break (final blank line inherits
  the preceding break). Trailing spaces retain advances but do not force wrap.
- Baseline distance is at least the adjacent rows' descent+ascent, and at least
  requested spacing times their maximum em size. Spacing range 0.6–3.0 remains
  bounded; this is minimum leading, avoiding automatically overlapping rows.
- Left/center/right align full visible ink/advance extents. Justify only soft
  wraps, distributing extra width once per interword space group regardless of
  style boundaries; hard-break/final rows stay left aligned.
- Request bounds use displayed page coordinates; returned origins/line metrics
  explicitly use raw PDF coordinates. All rotations/crop origins are tested.
- Layout is not a save/publication guarantee. It does not bypass graphics,
  neighbor collision, permissions, resource, or saved-output checks.

## Review focus

- A style boundary in the middle of an overlong word must not let it fit.
- Spaces spanning multiple styles must get one justification gap.
- Tall incoming rows and descending glyphs must fit the measured area.
- Empty/trailing hard-break rows must retain height and style provenance.
- Unknown IDs/nonfinite metrics/boundaries must fail atomically without source
  mutation; no truncation at fragment/text/line limits.
