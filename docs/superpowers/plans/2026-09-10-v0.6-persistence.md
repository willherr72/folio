# Folio v0.6 Implementation Plan

> Use the executing-plans workflow with independent native persistence, frontend geometry, and corpus workstreams under the dispatching-parallel-agents skill.

**Goal:** Portable editable text/ink and evidence-backed compatibility/performance coverage for issues #6/#7.
**Architecture:** Versioned owned standard annotations; normalized page-coordinate editor overlays; unchanged immutable sources and per-tab histories.
**Tech stack:** React/TypeScript, Tauri/Rust, PDFium, lopdf; development corpus tooling uses PyMuPDF/pypdf/Pillow.
**Spec:** docs/superpowers/specs/2026-09-10-v0.6-persistence-design.md

## Global constraints

Windows x64; local only; no source overwrites, network document processing, sidecars, or duplicated embedded source PDFs. Keep review annotations standard. Unknown persisted data retains its native appearance.

Files: src-tauri/src/types.rs, engine.rs, new focused persistence module, recovery.rs; src-tauri/tests/persistence.rs and existing regressions.
Interface: ExportRequest {pages, flatten?:boolean}; TextOverlay.rotation?:0|90|180|270. flatten defaultsfalse and affects only text/ink.

- [x] Validate crop/rotation combinations, malformed/stale metadata, source independence and legacy recovery import markers.
