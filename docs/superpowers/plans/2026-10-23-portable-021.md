> **For agentic workers:** Use superpowers:executing-plans for inline execution.

**Goal:** Deliver an independently checked local portable package consolidating
form page selection/zoom/navigation and paragraph font size/alignment/line spacing.

**Architecture:** Reuse the versioned portable packager and isolated Windows
acceptance scripts. Keep every earlier package immutable. This remains a local
development checkpoint, without publication, commit or a parity claim.

**Spec:** Version0.21.0-dev.1 in package/package-lock, Cargo/Cargo.lock and Tauri.
Before packaging, show inferred line spacing to at most four decimal places;
preserve the exact untouched inferred native value by omitting the formatting
override. Track whether the user explicitly edited spacing. Explicit input—even
the same number as the rounded display—must be passed as entered; Reset restores
the display and clears the override. Selection reset also clears it. This resolves
the observed quiz display1.2200012 without changing its default output geometry.
No other production behavior changes are planned. Native code since the accepted
spacing checkpoint is unchanged except package metadata.
