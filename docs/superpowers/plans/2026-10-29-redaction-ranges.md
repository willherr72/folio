# Partial Text Redaction Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans inline, one final review.

**Goal:** Remove exact inspected text ranges while preserving retained source positions and exposing native character advance geometry.
**Architecture:** Reuse canonical source binding and fresh publication; interpret text/graphics state, replace removed glyphs with bounded TJ displacements, reparse output and compare retained geometry.
**Tech Stack:** Existing Rust/lopdf/standard-font tables, PDFium and MuPDF/pypdf acceptance. No new dependencies.
**Spec:** docs/superpowers/specs/2026-10-29-redaction-ranges-design.md

## Global constraints
Private API only; no GUI/CLI/worker commands, source-file overwrite, package rebuild or commits. Existing isolated worktree, one Cargo process with --locked --offline and one build job. Retain A's 1000 pages/100000 objects/100000 operations/500000 tokens/8 MiB per page/64 MiB cumulative and output/1 MiB text/depth64/4096 array elements/16 operands. At most4096 nonoverlapping ranges; finite magnitudes<=1000000. Retained baseline origins and endpoints must survive serialization within0.002pt. Independent raster acceptance remains exact outside source-selected ink.

## Review focus
- Default StandardEncoding punctuation must use its actual nominal glyph widths, not WinAnsi ASCII guesses.
- q/Q restores native text and line matrices; following Td/T*/quote operations preserve their own source geometry.
- f32 serialization drift must be checked after parsing output, not only before encoding.
- Selected spaces retain Tc/Tw/Tz effects; preexisting TJ numbers and following shows remain ordered.
- Fragmentation must not bypass global output allocation/operation/token budgets.
