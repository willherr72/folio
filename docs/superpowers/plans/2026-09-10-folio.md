# Folio Implementation Plan
> For agentic workers: use superpowers:subagent-driven-development for independent units and requesting-code-review for final review.

**Goal:** Deliver a runnable local Windows PDF editor prototype.
**Architecture:** Tauri UI exchanges native render bytes and a declarative edit plan with a Rust/PDFium worker.
**Tech Stack:** Tauri 2, Rust, PDFium, TypeScript, Vite, Vitest, Playwright.
**Spec:** docs/superpowers/specs/2026-09-10-folio-design.md

## Global constraints
- All runtime PDF operations stay local. No AI, accounts or telemetry.
- Windows x64 first; native engine.
- Source PDFs never silently overwritten.
- API and coordinate contract are defined in the spec; frontend and backend must agree.
- Prototype performance claims must be measured.

## Task 1: Native backend
Files: src-tauri/Cargo.toml, build.rs, src/*.rs, tests/*.rs, tauri.conf.json, capabilities/*.json.
- [ ] Read API and coordinate contract.
- [ ] Write integration tests for export/reopen, text/ink, reorder and intrinsic rotation; run failing.
- [ ] Implement worker document lifecycle, render bytes, validated export, native dialogs and Tauri commands.
- [ ] Run backend tests and cargo check. Keep test evidence in artifacts/backend-report.md.

## Task 2: Desktop UI
Files: package.json, index.html, tsconfig.json, vite.config.ts, src/*, tests/*.
- [ ] Write state/coordinate tests and observe failure.
- [ ] Implement sidebar, toolbar, single page viewport, text properties, signature pad, page tools, keyboard shortcuts and undo/redo.
- [ ] Add explicit demo mode adapter with deterministic sample documents for browser UI tests.
- [ ] Run unit tests, typecheck and production build. Keep evidence in artifacts/frontend-report.md.

## Task 3: Integration and delivery
Files: scripts/*, README.md, LICENSE, THIRD_PARTY_NOTICES.md, artifacts/*.
- [ ] Acquire pinned engine build, retain license/provenance and check hash.
- [ ] Connect API, run real PDF integration and automated UI smoke checks.
- [ ] Create release executable and launcher; verify engine discovery from distributed location.
- [ ] Request independent whole-project review, address substantial findings, rerun affected checks.
- [ ] Commit source and write morning handoff with exact launch command, features and limitations.
