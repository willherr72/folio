# Automatic fitting for edited paragraph previews

Intent: adding words directly in the paragraph workspace should reach a checked PDF preview without a separate geometry-repair action. Existing Edit text transfers already fit their changed draft, while StyledParagraphDialog.makePreview currently sends direct edits with their old area.

Approach: use the existing native styled paragraph fitter before Preview for content/layout changes. A default-on **Automatically fit edited text** checkbox is available when the adapter supplies fitting. An explicit fixed-area preference, manual area edits, reset and history navigation retain their exact area. Do not fit an untouched initial preview, caret selection or caret-only formatting. Turning fitting on with a pending content edit invalidates an old candidate; turning it off retains the explicit current request. Existing manual Fit remains a distinct undoable area action.

Alternatives considered: retain manual-only fitting (does not solve the observed workflow gap); fit on every keystroke (unnecessary native traffic and harder async/history ownership); chosen fit-before-preview makes the real PDF preview authoritative and uses existing source, collision and baseline checks.

The fit proposal is advisory. A failed or outside-page/crop proposal leaves text, formatting, selection and bounds unchanged and offers useful feedback; native Preview may still succeed with the unchanged area. Never shrink fonts, invent source glyphs or relax native eligibility. A successful proposal preserves the source baseline and merges into the current local edit, so one Undo/Redo restores text and geometry together. Local keyboard history, button history, manual positioning and shared-form occurrence routing must agree. Delayed source/owner/draft changes discard results. Font leases last through native completion; provider-owned rectangles are copied immediately. Caret-only updates during fitting are preserved. The rendered candidate must match the adopted request, and Apply remains unavailable until its actual raster is ready.
