# Verified JPEG coverage ownership

Continue parent JPEG phase 3 from the tested coverage geometry. A saved record is a hint, not evidence of redaction by itself. Keep ordinary JPEG page admission closed until the complete context/budget/disclosure integration is ready.

Store a direct image dictionary `/FolioJpegRedaction` with exactly `/V 1`, binary `/Mask`, and 32-byte binary `/Binding`. Reject indirect/unknown/null record structures, wrong versions, malformed lengths, nonbinary or empty masks, and records on non-JPEG images. Bind the canonical JPEG digest (including shape and effective color interpretation), MCU shape, and mask using a separate versioned SHA-256 domain. The version also identifies the canonical fill geometry algorithm. Owned image identity is the coverage binding, so equal JPEG bytes with different required fills cannot deduplicate incorrectly.

On load, validate and charge bounded record input and mask allocation. Canonicalize JPEG content, check its binding, then reapply the claimed mask under a separately charged codec work budget. The resulting canonical bytes must match exactly; a recomputable checksum cannot authorize retaining secret coefficients beneath a black overlay. Install ownership/cache/retained bytes only after both proofs pass. Count the retained mask with the JPEG bytes. Failed attempts keep consumed work charges and never install a cache entry.

Owned re-edit unions prior and new masks, rewrites those blocks, and retains the union. The low-level coefficient-only API must refuse already-owned images so it cannot silently discard their paint. Bound output bytes before subtracting mask storage. A matching record does not prove an occurrence has its paint: verify the exact expected following operator sequence for every Do, including aliases already loaded in the registry. Integer and real encodings with identical admitted numeric values may match; no missing/changed/interleaved operation is exempted.

The publication helper emits each owned fill immediately after its Do. Shared aliases and resource identity do not suppress repeated occurrence paint. Preserve later operators. Track current paths and pending clipping separately from q/Q state; refuse insertion that would consume another path, apply a pending clip, occur under an active clip, or exceed graphics nesting. The inverse source helper verifies context and the full following fill sequence before collapsing it into logical image ownership. Both helpers use explicit shared geometry/operation accounting; a source record alone never makes arbitrary paths exempt from area selection.

Testing must cover valid Gray/RGB save/reload, immutable source, stable repeated edits, equal coefficients with different coverage identity, forged bindings and claimed-but-unmodified coefficients, malformed records, effective-color changes, exact input/output/second-decode budgets, and per-occurrence paint failures after an earlier alias succeeds. Test actual fresh-graph publication/reload and second edits with independent readers and coefficient checks. Preserve outer-antialias and general resampling limitations from the geometry stage.

Remaining integration: connect the source helper to full canonicalization only with the complete transaction resource context, update ImageWork to select/retain JPEG variants and coverage, derive preview disclosure including reader resampling, then final integrated phase review and public UI/package acceptance. This model/publication stage is necessary progress, not full JPEG redaction or commercial parity.
