# Source-owned text-redaction selection

## Intent and authority
Move Folio from private offset removal toward on-page text marks. The prior turn made progress: actual selected-TJ and reader-isolated verification now covers 240 saved cases. Those checkpoint hashes were revalidated. The user authorized autonomous work without routine design questions. This design is the coordinator's choice, not a previously selected user requirement.

## Workflow and approach
Measure glyphs from the exact immutable source bytes, match their native Unicode/origins uniquely to the admitted source operands, and retain an opaque in-process inspection. A rectangle selects every whole nonspace glyph whose measured tight box has positive overlap; return the full affected glyph boxes so later UI can show overhang outside the drag rectangle. Interior source spaces between selected adjacent nonspace glyphs are included; leading/trailing spaces with no ink remain. This is text selection, not a promise to erase every image/path beneath a rectangle.

Reusing ordinary PageText is rejected because it contains generated whitespace and fallback bounds. Font advance rectangles are not glyph shape bounds. Use existing PDFium tight_bounds, origin and is_generated; no fallback to loose bounds or last_position. Tight boxes are native glyph bounds and may overestimate actual visible paint under clipping; do not call them pixel masks or all-content area coverage. Existing source clipping/path semantics stay admitted by the structural kernel.

## Interfaces and ownership
Create src-tauri/src/redaction_selection.rs as a private engine child module, plus redaction_selection_tests.rs under that module. Existing WorkerRuntime methods remain private: inspect_redaction_text_page(&self,source_id:&str,page_index:usize)->EngineResult<PageTextSelection>; redact_text_mark(&self,mark:&TextRedactionPlan)->EngineResult<RedactedTextRangesPdf>. No WorkerRequest, public PdfEngine/API command, serialization, candidate registration, UI or package in this milestone.

PageTextSelection and TextRedactionPlan have private fields/constructors. Inspection owns source ID, SHA256 of complete immutable source bytes, page index/dimensions and source-bound block/glyph mappings. Read-only accessors expose glyph code point, source offset/block and top-left point bounds for eventual UI projection. PageTextSelection::mark(rect:TextMarkRect)->EngineResult<TextRedactionPlan> uses only its owned measured data; callers do not supply glyph geometry, selection IDs or ranges. Mark plan owns source ID/hash, generated ranges, affected count and glyph boxes. It cannot be deserialized or constructed by another module. Applying rechecks source ID still open, current rights and complete bytes hash before parsing/recomputing range bindings. Closure, changed bytes and unknown source fail without output or source mutation.

Require editing_document and copying_document at inspection and application; reject printing-only and protected-policy sources explicitly until protected publication is implemented. The input is an already open source, capped at64MiB before additional parsing, loaded with lopdf LoadOptions max-decompressed-size64MiB. Existing full-document kernel admission remains authoritative: <=1000pages/100000objects/operations/500000tokens,8MiB/page/64MiBtotal/output,1MiBASCIItext,depth64/4096arrays/ranges, standard fonts and simple canonical geometry. This does not claim a new universally bounded hostile-file parser. Open a temporary native document from the same Arc bytes for measurement, avoiding dependence on an in-memory view whose annotations may have been imported. Native and parsed sources are thus bound to identical bytes; no native source regeneration or disk writes.

## Character mapping
Extend the narrow nominal font helper to return both width and actual Unicode scalar for each printable source byte in its admitted encoding. Extend private Glyph with that scalar; canonical source IDs/bytes and removal metrics stay unchanged. Default StandardEncoding apostrophe/backtick must match the native curly quote scalars. Do not infer identity from base-font names alone beyond existing kernel admission.

Inspect the whole source with existing range geometry, then map the requested page's nonspace source glyphs against non-generated native characters using Unicode and baseline origin within0.002pt. Do not assume extraction order equals content order. Each source glyph and native nonspace character must have exactly one match; duplicate/ambiguous/missing matches refuse. Standard space characters and generated line/space separators do not receive ink boxes. Non-generated unexpected characters refuse. Preserve original source block/byte offsets even when native order differs.

Use spatial hash cells0.004pt and adjacent cells with a maximum32source candidates per cell; bounded matching rather than pairwise scanning. Per page <=250000source glyphs and <=500000native characters before collecting native records; total source already bounded1MiB. Matching must reject ambiguity even if one competing candidate was already consumed. All bounds/origins finite with absolute components<=1000000; nonspace tight bounds must have positive area. Page rectangles are top-left physical points, within canonical zero-origin page bounds1..20000pt. Rectangle edges merely touching a glyph do not select it; dimensions must be positive and finite. Empty/no-hit/invalid marks refuse. Merge consecutive selected source offsets, including only intervening ASCII spaces; never bridge an unselected nonspace glyph or block. Check4096ranges before pushing and reuse kernel removed-character/output limits.

## Acceptance
Native tests: exact nonspace code/offset/bounds mapping; default vs WinAnsi punctuation; generated separators; same letters at different positions and reordered source/native text; spacing/affine states; ambiguous coincident glyph refusal; invalid/empty rectangles; interior-space inclusion; stale/closed/printing sources and source-byte identity; retained glyph positions after mark removal. Unit tests pin spatial bucket and range limits without huge allocations. Source buffers/doc counts remain unchanged on errors.

Measure all240 prior saved source fixtures through the new native inspector and record bound source/glyph receipts. Use a subset of the axis-aligned ordinary and positioned layouts for mark-to-output acceptance (target48cases:12faces x2encodings xplain/TJ-middle), requiring the rectangle to select exactly the intended source secret, then use the prior independent full output oracle. Record affine mapping separately; do not claim rectangular affine marks select exactly an arbitrary string when their whole-glyph boxes overlap neighbors. Keep original fixtures and all failed evidence. Both prior native focused tests and full library gate must pass. One design builder check and one final scoped implementation review; local corrections, no re-review. No public-redaction or parity claim.

Before public preview integration, add native multipage/multiblock and discontiguous/page-edge cases. Retain negative/adjacent-cell, native order reversal and count-boundary coverage gaps. Whole-glyph tight-box selection is not pixel-accurate clipping/all-content area removal. No public request, package or executable was added.
