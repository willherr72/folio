This continues phase 3 of `2026-11-02-jpeg-area-redaction.md`, after the owned-image model. It does not enable page admission or replace the remaining publication/ownership work.

The geometry object describes coverage only; it is not proof that an arbitrary source JPEG was sanitized or that a page contains its required paint.

Coalesce consecutive selected cells into horizontal runs, then join identical runs on immediately consecutive rows. Clip final blocks to the image dimensions. This preserves holes and gives deterministic rectangles without quadratic merging. Emit all rectangles as equally wound subpaths of one nonzero fill, enclosed by q/black-g/Q. A single fill avoids separately antialiased internal seams. Whole-page integration must still enforce graphics-state depth, opacity, pending-path rules, source ordering, and per-occurrence ownership before inserting or exempting these operations.

Normalize top-origin sample rectangles into bottom-origin image coordinates. Use explicit polygon endpoints rather than a width/height rectangle whose addition could round inward. Round non-endpoint fractions outward by one binary32 ULP. Keep exact 0/1 image edges. Bound both the actual shortest decimal serialization and a reader's binary32 interpretation, with directed binary64 parsing allowance. Transform these envelopes with the existing checked interval matrix. The resulting regions describe paint, not JPEG resampling fringe; do not feed either back into source selection.
