# Opaque saved graphics states in text removal

Intent: remove existing text in common producer PDFs while preserving saved painting settings. The original user quiz uses one ExtGState with OP false, op false, OPM 1, SA false, SM 0.02. This currently refuses at the content preflight. Other producer/font limits may remain; acceptance must report them honestly.

Approaches: dropping gs would silently change painting; importing arbitrary resource graphs would broaden ownership and memory risks. Chosen coordinator approach: validate a small scalar dictionary, retain exact values and gs position, rename resources deterministically, and publish only the proved state into the fresh graph. Existing source originals remain untouched.

Admit only Type=ExtGState (optional); OP/op/SA booleans; OPM integer 0 or 1; SM finite 0..1; CA/ca exactly numeric 1; BM name Normal; SMask name None. Missing entries preserve inheritance. No injected defaults. Unsupported keys including Font/TR/HT/LW or nonopaque values refuse. Direct or indirect dictionaries/scalars resolve through at most 64 references with cycle detection. Unknown fields are refused even when value is null. Do not admit images, forms, annotations, soft masks, transparency, or marked content.

New redaction_graphics module owns reference-free normalized State dictionaries with stable digests. A document Registry deduplicates up to 256 distinct states; page resolver uses at most 64 unique states. Limits apply before inserting beyond capacity. Dictionary <=10 entries, only bounded scalar values; no stream/array/string allocations. Deterministic field order and typed digest protect selection identity. Repeated aliases/pages share Arc state and one output dictionary. No arbitrary source references survive.

Canonicalizer admits gs only with one Name operand; calls page state resolver and renames to G0 etc. Keep gs at exact operation position including inside BT and q/Q. Range scanner need not alter text geometry: no permitted entry modifies font/matrix/advance. Add state digests to whole-document selection identity. Publisher installs ExtGState only when used. Native glyph validation and history/preview ownership are unchanged.

Acceptance: RED/GREEN source removal and re-edit; malformed/missing resources, cycles, unknown fields, opacity/blend refusal, boundary limits; aliases, inherited resources, multiple states and q/Q; stale selection after state mutation; exact preserved settings and unchanged retained glyph positions. Emit synthetic saved outputs with artwork for independent raster checks using a source-defined removal mask and an outside-mask bad control. Probe the original quiz locally without logging its text or copying it into distributable output. Record remaining blockers. Full native library/bins check, source fingerprint, one final review. No frontend behavior change; no desktop/release/parity claim from this native milestone. Preserve previous runnable checkpoint; optimized build/desktop integration can follow separately.
