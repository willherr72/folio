# Portable Folio 0.25 integration

Deliver the verified paragraph fitting, source-baseline preservation, bordered
callout editing and bounded text-discovery reuse in one optimized local Windows
desktop/CLI package. The user authorized autonomous development and opted out of
routine design questions. Version0.25.0-dev.1 is the coordinator's integration
choice; it is not a public release or a claim of commercial parity.

## Approach

Keeping only debug candidates leaves the user without a current combined package.
Adding more features first increases the unintegrated delta. Choose fresh optimized
assembly through the existing staged build/ZIP workflow, preserving0.24 and every
original. Reuse established meaningful tests and saved-output audits, with fresh
package bindings and captured runtime helpers. No dependency/renderer upgrades.

## Scope and gates

Close the existing-text cache review before changing product metadata. Capture
the exact source, native/frontend tests, build inputs, predecessor package/archive
and seven metadata/documentation baselines. Change only the five root version
manifests plus README/CHANGELOG; preserve all other product bytes. Freeze these
inputs throughout verification and assembly. Use the existing isolated worktree,
one Cargo at a time, locked/offline/jobs1 and the shared target directory.

Run a fresh complete default native suite on0.25 metadata, explicitly enabled
original-Word controls, frontend suite, packaging tests and launcher checks. Record
ignored tests and incomplete/failed gates honestly. Build optimized desktop and
CLI binaries, verify every package/archive entry and extract to a fresh owned
directory outside the checkout. Test invalid working-directory renderer selection
and offline assets. Preserve prior output directories rather than overwriting them.

Run established CLI/MCP consecutive editing/form/font workflows and real Windows
text, paragraph, OCR and original-quiz workflows against the extracted package.
Add the current Word/mixed23-cycle cache checks and narrowed Word Apply/Undo/Redo/
save/reopen audit. Recheck current producer paragraph fitting/baselines and clipped
paragraphs through optimized CLI with independent saved text, fonts, positions,
surrounding pixels and nonempty tag/link structure where present. Preserve known
strict audit failures, including unused ReportLab resource removal, separately.

Capture/hash runtime helpers, source originals and executable/renderer identity.
Stop only owned test processes by exact path and UTC startup ticks. Reverify package,
predecessor, originals and source after acceptance; repeat assembly must refuse the
existing outputs. Final scoped review then one correction pass and a checkpoint
with exact scope/limits. No commits, pushes, publication or user-app restarts.

## Limits

Integration correction: the first full native gate exposed three request
constructors in two developer examples missing the existing `baseline_anchor`
field. Forward the inspected selection's anchor, preserving all other example
bytes. Bind example inputs in the corrected gate and keep the failed attempt.
This initially expanded the integration delta to two developer examples while
executable product sources, dependencies, renderer and tests remained unchanged.

The subsequent full native run reproduced a paragraph automation regression:
Fit-added headroom is interpreted as a baseline movement when its returned area
is reused. Apply the separately specified correction in
`2026-10-29-automation-paragraph-baseline-design.md`: two automation runtime files,
five affected test files and automation documentation. Align two direct-native
comparison requests with the existing CLI source-baseline default, retaining exact
rendered equality. Keep failed runs and original source/test bindings, prove the
bounded correction, then establish fresh full-native and package bindings. The
renderer, dependencies, native layout engine and desktop source remain unchanged.

Sampled development-host resource budgets do not prove low-memory hardware or
leak-free behavior. Physical printing, secure redaction, certificate signatures and
broad script/font editing remain separate requirements of the overall goal. The
native opening timeout recorded in the cache milestone remains unexplained; fresh
dialog-dismissal checks distinguish that boundary without hiding a future failure.
