# Complete MuPDF JPEG influence composition

Connect the existing decoder, crop, box-reduction, grid-fit, fractional-scale and
fixed-point affine bounds to source-bound JPEG selection. Keep the full public
JPEG redaction objective and immutable MCU mask intact. No renderer state enters
the publisher. The installed MuPDF 1.27.1 reference is a finite compatibility
contract, not a claim about every reader or zoom.

Build bounded possible native stages from outward interval geometry. Starting
with an image-unit-to-device frame in native top-row coordinates, fit the grid,
derive the inverse clip footprint and native scaler-support expansion, and
enumerate the resulting integer source rectangles. Apply the default decode
tuning thresholds and total-factor alignment. Include same-key higher-resolution
cache tiles and full-image cache fallback. Keep original tile windows, actual
decode factor, extra box reduction, returned extents and local frame together.
Do not describe a cached full tile using the requested crop's frame.

Compose the post-decode scaling routes: exact-axis and quarter-turn scaling
updates the frame to the returned scaled bitmap; general scaling retains the
frame while changing sample dimensions. Include no-scaling/interpolation choices
and supported fallback branches. Then use the existing fixed-point affine bound.
Share bounded work/rectangle accounting across alternatives and selected images.
Treat excessive ambiguity or unsafe arithmetic as compatibility refusal, never
as permission to expand source removal or silently replace the whole image.

Product code is independent Rust interval/bound arithmetic. Pinned native source
is audit reference, not copied into the product. Test with installed native image
decoding and draw devices, saved original/rewritten JPEG PDFs, cache changes,
clipped partial edges, reflections and branch thresholds. Retain negative controls
and independently verify saved bytes. Full opaque fill and combined private/UI
acceptance remain on the parent plan after both reader connections are complete.

The source-bound MuPDF entry receives the interpreter's initial page-to-device
matrix and requires an identity draw-device transform. Retain original cm
operands along the active q/Q path and replay from that initial matrix; multiplying
it by an already-combined content matrix would change floating-point order.
Then apply the PDF image row flip. Bound active retained sequences to 4096
transforms and total selected copies to 65536; charge transform replay to the
shared rendering-work budget. Existing PDFium behavior is unchanged in this step.
