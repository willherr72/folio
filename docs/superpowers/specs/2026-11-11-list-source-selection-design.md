## Approaches

1. Geometry-only normalization: a small change, but a rectangle alone cannot establish selection ownership or source label identity.
2. **Chosen by the agent:** capture native source-state metadata per affected widget, decode actual source labels through their bound font resources, verify native glyph ink in a bounded isolated appearance/font probe, and move only the proved variable region into the existing answer slot. Keep the original frame proof and transplant.
3. Whole-appearance regeneration: simplifies selection handling but may replace original artwork and frame style. It does not satisfy the preservation requirement.
