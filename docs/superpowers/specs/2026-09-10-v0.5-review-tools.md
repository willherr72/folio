# Folio v0.5: signatures and review annotations

Approved scope: issues #4 and #5, the next milestone in the user's release sequence.

Save named drawn signatures locally with preview, reuse, rename and delete. Continue existing cursor placement and undo. Add proportional size controls for placed ink. Signatures are visual marks, not certificate signing.

Add Highlight and Comment tools. Highlight embedded text using source glyph coordinates, including multiline text and intrinsic/editor rotation. Image-only pages explain that selectable text is required. Comments have page anchors and a document review list with navigation, editing and deletion. Edits use existing per-tab histories and recovery.

Use standard PDF Highlight and Text annotations, imported into editable overlays on opening. Remove successfully imported annotations from the in-memory source to prevent duplicate rendering; retain unrecognized annotations. Original source bytes remain unchanged for recovery. Export writes annotation geometry in PDF coordinates. This release restores highlight/comment editability; general text/ink persistence remains issue #7.

Verification: focused unit/component tests, native annotation roundtrips and rotated/cropped geometry, independent PDF-reader inspection, browser and packaged desktop smoke, existing suite. Publish v0.5 after verified build and close only completed milestone issues.
