# Duplicate tagged PDF pages without losing ownership

## Objective and authority

Continue the broad Folio quality goal by making the existing Duplicate pages action save supported tagged PDFs faithfully. Prior checkpoint: `artifacts/deleted-page-navigation-20261030/continuation.json`, fingerprint `7bcbc30f945e613adf1c394acc4ceaf46b1cb81454e9c5a6c31badba5734be65`. That turn was verified progress; no old workload is live. Routine decisions and implementation are authorized without permission questions. No commit, release, portable overwrite or original-file mutation.

## Chosen approach

Extend graph-native Save with an occurrence adapter after unique-page selection. Clone each repeated Page dictionary, its annotations, its selected logical structure and marked owners. Keep unaffected immutable font/image/content payloads shared. Use reverse dependency propagation to copy only resource/appearance containers that must point at a cloned owner; handle aliases, cycles and forward references without recursive whole-source cloning. Reserve cumulative retained bytes and graph complexity before cloning encoded payloads.

Importing the complete source once per occurrence multiplies unrelated payloads and does not meet this design. Renderer imports without independent tags lose the graph ownership this route exists to preserve. The existing page-resource importer is not sufficient: it recursively clones whole resources and cannot establish tag ownership.

## User-visible semantics

- The first requested occurrence keeps the canonical original page identity. Additional occurrences receive independent page/annotation/tag identities, rotation and crop. Untouched content must render and extract exactly like the source.
- Preserve current importer behavior (`link_navigation.rs`): self-links on a page copy go to that copy. Other local links and source bookmarks use the first requested occurrence of their target. Remote destinations remain remote. Do not invent duplicate bookmark trees.
- Preserve Name and String destination namespaces. A self-targeting named operand in a copy gets a collision-free copy-local binding, preserving the original named entry and metadata. Other operands remain unchanged. Use the existing typed action walker; shared actions within one copy stay shared, while originals and different copies cannot contaminate each other's targets.
- Preserve authored logical order in the original structure. Independent copied subtrees are appended in requested duplicate order. This continues the existing distinction between physical page arrangement and authored tag order; it does not implement a tagged reading-order editor or certify accessibility.
- Do not silently split semantic descriptions, IDs or table relationships. Reuse existing partial-selection checks for Alt/ActualText/E and A/C. Clone admitted complete structure attributes/classes/identifiers and reconcile typed ID/Header relationships through the existing structure merger. A partial relationship that cannot be represented faithfully remains an explicit refusal, not a lossy fallback.
- Empty structure elements with explicit or inherited page ownership follow that page's copy. An empty element with no provable page ownership is refused during duplication; do not assign document-level descriptions to arbitrary copies. Ordinary unique-page selection keeps its existing behavior.
- Indirect mutable table attributes and their containers must be independent across occurrences, including ClassMap aliases and attribute streams. A/ClassMap sharing within an occurrence remains intact. Page-local reply actions use the normal action walker regardless of Annots order; additional action guards remain for related annotations outside that primary set.
- Keep permissions, encryption, cancellation, atomic publication and current-source provenance. Combined forms/added/imported overlays remain their own roadmap work; this adapter does not erase their guards.

## Architecture

1. Import each contributing current source once and assemble complete original graphs using current catalog/language/navigation validation. Decide outline intent against occurrence-aware internal page tokens. First occurrences use the source/page token; later copies have distinct tokens so requesting a bookmark on a copy is not misclassified as unchanged.
2. Select the unique surviving canonical pages using the existing page/navigation projection. Original deleted-page semantics remain unchanged. Materialize inherited resources/geometry before any new copy.
3. Expose a bounded read-only structure selection plan from `composition_projection`: selected root K, field overrides, selected element identities and marked/whole owner sets. For cloning, discarded IDs do not delete original IDs; rebuild a copy-local ID tree for retained elements. Existing partial-description/attribute guards still apply. Cache a plan per repeated original page within cumulative metadata/work limits.
4. Allocate all copied Page, annotation, selected StructElem/root and selected marked-owner IDs before rewriting references. Discover dependency edges from their needed values/resources; pages/page trees/catalogs and structure identities are typed boundaries, not invitations to recursively copy the document. Propagate copy requirements backward from cloned owners through resource/appearance containers. Immutable unaffected objects retain original identities. Related annotation Popup/IRT references must remain coherent; source annotation P must match its owning page before copying. Unknown ownership or external page/catalog dependencies require an explicit guarded decision.
5. Clone only admitted values after byte/complexity reservation. Rewrite references to copied owners and structure nodes without duplicating shared dependencies inside a copy. Patch Page Parent, annotation P and structure Pg explicitly. Do not generically redirect arbitrary navigation to a copied page. Plain page content streams can remain shared: their MCIDs are scoped by independent page StructParents. Marked form/stream owners that acquire a new parent must have independent dictionaries and encoded payloads.
6. Build one sparse StructureInfo per copy with exact MCID/null slots, OBJR targets, inherited Pg and selected ID tree. Merge original and all copied structures once, using the existing role/class/ID/attribute reconciliation. This avoids repeatedly qualifying original IDs for each copy. Unselected marked resources can remain shared with their original ownership; selected marked owners must be cloned. Final bidirectional inspection is mandatory.
7. Publish the final flat page sequence, then retarget only copied-page typed navigation with the existing walker. Extend Prepared with bounded copy-local destination bindings and staged catalogs. Original outline objects and action targets remain intact. Unknown scripts, action kinds, presentation navigation and unsupported AA triggers remain guarded for copies.
8. Apply compatible explicit bookmark reconstruction only after final page identities exist; original compatibility/language checks must run first. Preserve explicit discard semantics. Validate pages, structure, outlines, typed destinations/actions and retained limits before outer serialization/protection/publication.

## Limits and ownership

Keep current limits: 100,000 objects, 1,000,000 values/steps, 256 MiB retained stored bytes, 64 MiB per stored stream, depth64; staged navigation/structure metadata16 MiB, action/outline depth32 and 4,000 outline items. Budgets are cumulative over all copies, checked before allocation or payload clone. These are retained-data bounds, not total-process RSS claims. Use an owned scratch graph; cancellation or error cannot change an open source or an existing destination. No renderer substitution or limit increases.

Cover canonical alias identities; two copies and interleaved copies; shared marked forms and unmarked large image/font payload sharing; annotation/appearance/Popup ownership; source-order structure and sparse reverse slots; unique IDs and header relations; self named/explicit links, cross-page targets, remote Next and action sharing; distinct occurrence bookmark intent; crop/rotation independence; repeated save/reopen; stale/unsupported relationships; cancellation at staged boundaries and cumulative memory refusal.

Use authored Word/Pictures navigation PDFs. Native and independent-reader audits compare exact1x/2x pixels, raw text/images, occurrence-specific targets, raw outline metadata and bidirectional tag ownership. Include a copy edit/rotation that leaves the first occurrence unchanged, and damaged-output controls for reused tag ownership, changed self-link targets and lost sharing. Fresh source-bound GUI/CLI build, owned Windows Duplicate/Undo/Redo/Save/reopen/bookmark checks, then one final scoped review.
