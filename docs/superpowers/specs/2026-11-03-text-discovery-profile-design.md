The accepted admission-reuse GUI completes the dense-document workflow, but selection preparation still takes appreciable time. The prior worker profile attributes much of ordinary text discovery to source parsing in transparency-group inspection, resource admission, form projection and source-context inspection. That profile predates admission reuse, so a current diagnostic will distinguish first discovery from repeated discovery before selecting another optimization.

Use the existing bounded, thread-local wall-clock span collector and temporary feature-gated worker binary. Retain the existing stage names so accounting remains comparable; add spans for font proofs, source text and substitution eligibility only if exact function boundaries can be identified. No semantic validation, policy, font, geometry, graph, serialization or lifetime behavior changes. Timers retain static names, integer timestamps and parent indices, with the existing 4,096-event bound.

Run seven alternating header edits in three sequential sequences: observed two-page, observed 300-page, and collection-disabled 300-page. Each edit performs the real occurrence text/form discovery for pages zero and one twice; exact serialized discovery results and selection indices must match within that source version. Private candidates must not escape; eight source versions remain until explicit closure. The control retains disabled instrumentation call sites and cannot prove zero overhead.

Bind fixtures and final saved-reference PDFs to the accepted desktop checkpoint. Audit all 602 final pages independently for original-relative text, glyph styles/positions, fixed source-derived pixel region, geometry, and exact comparison with accepted desktop saves. Every measured interval must reconcile to exclusive spans plus the bounded timer boundary. Corrupt phase order, nesting, route labels, equality receipts and references must fail validation.

The accepted production baseline is 30d628a61d47b9b0e2b04f42476f652aaac6b6dce97c64100e060a01b74bb1fa. Snapshot all temporary edits before installation, reject concurrent drift, retain the instrumented snapshot/executable, and restore original bytes after the run even if build or execution fails. A complete product fingerprint must match again before this diagnostic is closed. The accepted GUI remains untouched.

This is direct worker wall time, with no IPC queue or GUI Save route. Sequential synthetic fixtures on one host do not establish isolated page-count causality, randomized speedup, CPU-time attribution, broad compatibility, memory quality or commercial parity. No new cache or parser-sharing behavior is authorized by the diagnostic itself; choose the next implementation from the evidence and preserve parser admission semantics.
