## Intent and authority

Deliver the accepted post0.26 editing and structured-save work in a new optimized Windows desktop plus CLI/MCP package. The user's standing instruction authorizes autonomous routine choices. Preserve existing packages, original documents, failed evidence and the dirty worktree. This is development integration, not publication, commercial parity, accessibility certification or a universal PDF compatibility claim.

## Approach

Coordinator choice: version `0.27.0-dev.1`, using the existing `scripts/build-portable.ps1` and archive verifier. Overwriting0.26 would destroy a verified reference. Relabeling the debug candidate would not test release optimization, bundled assets or operation outside the checkout. Rebuilding every unchanged test target solely for version literals adds no behavioral coverage; instead, prove the exact five-file/six-literal version delta and execute fresh optimized-package workflows. Any additional runtime/dependency/renderer/test change invalidates that reuse and requires affected verification before packaging proceeds.

Keep the existing Windows/WebView2 prerequisite. Bundle desktop and console executables, pinned PDFium, offline OCR assets, examples, instructions and dependency licenses as the existing format requires. No installer, updater, dependency upgrade or new product feature belongs in this milestone.
