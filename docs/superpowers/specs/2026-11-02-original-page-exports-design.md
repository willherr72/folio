# Original-page read exports

Folio 0.31 opens the public IRS W-4 and NIST FIPS 197, but text/image export fails because page composition attempts to rebuild unsupported form graphs. The reproduced errors and unchanged input hashes are in `artifacts/producer-corpus-discovery-20261102`.

Read-only text, PNG/JPEG and page-preview output will use a private full-source document plus an explicit selected page index. An unchanged page can borrow immutable source bytes. Edited pages retain the complete original graph and apply the current overlay draft using existing source-bound annotation proofs and appearance generation, followed by crop and rotation. Private views change the selected page drawing list and optionally append generated drawing content for text extraction; original annotation objects, script targets, and structure consumers remain in the transient graph. These intermediate bytes never become an editable saved PDF or a retained document source. Unbound legacy recovery drafts use the previous guarded visual read route without receiving publication authority. No AcroForm projection, form repair, XFA removal, or editable-PDF publication belongs to the full-source route. If strict graph page-tree inspection cannot establish unique source leaves, retain the previous guarded page-copy read route; this preserves existing cropped read support for repeated leaves without relaxing Save or form validation.

The shared result is internal only: bytes, page index and source-owned physical unit. Every consumer must use the selected index for pixels, ordinary/OCR text, and optional form values. Source validation, permissions, resource limits, cancellation, and atomic output ownership remain mandatory. Text export flattens current drawing overlays so their text is included; image/preview output retains appearances. Unsupported optional form-value extraction may still refuse explicitly. Editing eligibility and Save remain outside this milestone.

Alternatives rejected: weakening form preservation permits unsafe saved PDFs; borrowing original bytes for every request loses unsaved/deleted annotations; a clean-page-only fix leaves ordinary edited export broken. Reusing bounded overlay publication avoids another drawing implementation.

Acceptance: generated orphan-widget and XFA static-page fixtures; second-page selection; crop/rotation/UserUnit; changed/deleted/imported overlays; native appearance retention; cancellation/permissions/OCR regressions; unchanged real source bytes and independently checked real output. This does not claim dynamic XFA rendering or editing, nor commercial parity.
