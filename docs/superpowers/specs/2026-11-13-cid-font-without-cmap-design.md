# Editing CID TrueType subsets without an internal cmap

The public `source-font-guidance-20261113/fixtures/Source-Font.pdf` reproduces a valid map-free CIDFontType2 subset. Current `embedded_font::verify_domain` rejects the absent internal TrueType cmap before using the PDF's Identity-H/ToUnicode/CIDToGIDMap and widths, also leaving its resource unproved and blocking the standard-font neighbor. No private source is needed.

For existing-text editing only, accept a truly absent internal cmap on static embedded TrueType CIDFontType2 resources when the existing bounded PDF mapping/glyph/metric proof succeeds. A present but malformed cmap must remain an error. Simple TrueType, implicit legacy encodings, complete form-font repertoire proof (`all_scalars`), CFF, shaping and unsupported encodings keep their existing admission rules.

An accepted map-free proof must require exact source operands and preserve source encoding. It may encode only Unicode scalars actually represented by the bounded PDF ToUnicode proof, mapped through the actual CID-to-GID mapping (including existing Identity/default handling), nonzero/in-range glyphs and matching finite PDF/program advances. Existing ambiguity/size/scalar exclusions remain authoritative. A font name or native extraction alone grants no authority. Do not generate a cmap or silently use an installed font.

The stream-preserving edit path is preferred for map-free fonts, so native regeneration cannot guess an absent Unicode reverse mapping. The original font bytes and PDF resource maps must survive original-font edit/save/reopen/re-edit; explicit substitution remains a separate user choice. Standard-font neighbors should become editable only because the CID resource has now earned the same mapping proof as other allowed resources, not via a global preflight bypass.

Approaches: rejecting these PDFs perpetuates a reproduced mainstream encoding gap; synthesizing a TrueType cmap or falling back to a face name would invent authority. The chosen approach uses the PDF CID mapping already consumed by the verifier and conservatively selects exact source-operand/encoding preservation. Implementation is expected in embedded_font.rs only, with separate focused tests, unless native evidence demonstrates a further necessary defect.

Required evidence: public DejaVu-derived cmap-free fixture, exact mapped/Identity/default glyph-code proof, malformed/ambiguous/out-of-range/width/unsupported-source rejection, original-font no-op/delete/growth and exact bytes/maps across save/reopen/re-edit, explicit font substitution, neighboring Helvetica edit, paragraph reflow, independent saved-PDF extraction/raster checks and a current compiled Windows workflow. Do not imply every missing-map font is editable; preserve refusal when proofs or layout fail.
